Project Overview

PriceSense is a web-based Fuel Price Prediction System developed as a Final Year Diploma Internship Project. The system predicts Petrol and Diesel prices using historical fuel prices, Brent crude oil prices, taxation information and Deep Learning techniques.

Project Objective

  • Predict future Petrol prices.
  • Predict future Diesel prices.
  • Analyze historical fuel price trends.
  • Visualize data using charts.
  • Evaluate model performance.

Technology Stack

Programming Language Python
Framework Flask
Machine Learning TensorFlow
Libraries NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
Frontend HTML, CSS, JavaScript

Project Features

  • Secure Login System
  • Dashboard
  • Fuel Price Prediction
  • Analysis Charts
  • Prediction History
  • Model Performance Report
