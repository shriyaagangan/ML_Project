PriceSense Dynamic Fuel Price Forecast Platform

PriceSense is an AI-powered fuel price forecasting platform developed as a Final Year Diploma Internship Project. The system predicts future Petrol and Diesel prices using historical fuel prices, Brent crude oil prices, taxation information and Deep Learning.

Project Overview

PriceSense is a web-based Fuel Price Prediction System developed as a Final Year Diploma Internship Project. The system predicts Petrol and Diesel prices using historical fuel prices, Brent crude oil prices, taxation information and Deep Learning techniques.

Project Objectives

  • Predict future Petrol prices using AI.
  • Predict future Diesel prices accurately.
  • Analyze historical fuel price trends.
  • Visualize fuel price data using charts.
  • Evaluate model performance with MAE and R² Score.
