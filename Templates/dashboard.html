Project Overview

PriceSense is an AI-powered web application developed using Python, TensorFlow and Flask. The system predicts future Petrol and Diesel prices using historical fuel prices, Brent crude oil, tax percentage and previous fuel prices. It also provides data visualization, prediction history and performance reports.
